# 💊 Pharmacy Management System

A web-based application designed to manage medicine inventory and customer registration efficiently. The system provides a simple interface to add, search, view, and delete medicine records.

## 📌 Project Overview

The Pharmacy Management System connects a web interface with a Java Servlet backend and a MySQL database. It uses JDBC to store and retrieve medicine information.

## ✨ Features

- **Add Medicine** – Add medicine details to the inventory.
- **Search Medicine** – Search for medicines by their details.
- **View Inventory** – View available medicine records.
- **Delete Medicine** – Remove medicine records from the inventory.
- **Customer Registration** – Provide a customer registration interface.
- **Database Connectivity** – Connect the application to MySQL using JDBC.
- **Form Validation** – Validate user inputs using JavaScript.

Java Servlet and database connection files are part of the backend, where included in the project.

## ▶️ How to Run

1. Install Java JDK, Apache Tomcat, and MySQL.
2. Import the project into Eclipse IDE.
3. Create the `pharmacy_db` database in MySQL.
4. Configure the JDBC connection and MySQL Connector/J.
5. Configure Apache Tomcat in Eclipse.
6. Run the web application on the Tomcat server.
7. Open the application in your browser.

## 🎯 Objective

To simplify medicine inventory management and customer registration through a web-based application backed by a MySQL database.
