# Pharmacy Management System

A web-based Pharmacy Management System designed to manage medicine details and simplify pharmacy inventory operations.

## Features
- View medicine details
- Add new medicines
- Manage medicine information
- User-friendly web interface

## Technologies Used
- HTML
- CSS
- Java
- Java Servlets
- JDBC
- MySQL

## Database
Database name: `pharmacy_db`

## How to Run
1. Install JDK, Apache Tomcat, and MySQL.
2. Configure the database connection.
3. Deploy the project on Apache Tomcat.
4. Open the application in your browser.

## Project Purpose
This project demonstrates web development, Java servlet programming, and database connectivity for pharmacy management.
